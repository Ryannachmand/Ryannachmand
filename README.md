## Featured Repositories

### 🧬 Bone Marrow Spatial Imaging Pipeline

🔗 https://github.com/BoneMarrowMxIFImaging/MDS.Manuscript

End-to-end pipeline for multiplex immunofluorescence image analysis and spatial biology across millions of spatially resolved cells. Introduces **MDS-MAPS**, a computational framework for quantifying bone marrow microarchitecture and disease-associated spatial remodeling.

---

### 🤖 scRNAseq-skills-v2

🔗 https://github.com/Ryannachmand/scrnaseq-skills-v2

Open framework for agent-assisted single-cell RNA-seq analysis. Modular computational workflows enable reproducible, reusable analysis pipelines built around modern Seurat and Scanpy methodologies.

---

### 🖥️ Lab Analysis Platform

🔗 https://github.com/Ryannachmand/lab-analysis-platform

Interactive software platform for executing AI-assisted computational biology workflows through a graphical interface. Designed to make advanced bioinformatics analyses accessible to researchers without programming experience. Currently under active development.
